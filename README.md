# Портфолио Ольги Смирновой

Готовый статичный сайт для GitHub Pages. Экспорт из актуальных исходников Sites 12 октября 2026 года.

## Что внутри

- `index.html` — страница с CSS и JavaScript. Сборка и установка программ не нужны.
- `assets/` — портрет и четыре макета кейсов. Все ссылки относительные и работают при размещении в подпапке репозитория.
- `.nojekyll` — отключает обработку файлов через Jekyll.
- `README.md` — эта инструкция.

В отдельном файле `olga-smirnova-latest.html` все пять изображений встроены в HTML. Для пакета они вынесены в папку `assets`; содержание и оформление те же.

## Публикация через сайт GitHub

1. Создай публичный репозиторий в своём аккаунте. Например, `olga-smirnova-portfolio`. Ветка для публикации — `main`. Если репозиторий уже есть, используй его, предварительно проверив, что загрузка не заменит другой сайт.
2. Распакуй ZIP на компьютере. Загрузи **содержимое** распакованной папки через **Add file → Upload files**. Файл `index.html` должен лежать в корне репозитория, рядом с папкой `assets`, а не внутри дополнительной папки. Сам ZIP загружать не нужно.
3. Сохрани изменения в ветку `main` кнопкой **Commit changes**. Если скрытый файл `.nojekyll` не попал в загрузку, создай его через **Add file → Create new file**. Допустимо добавить комментарий в этот файл, если интерфейс не сохраняет пустой файл.
4. Открой **Settings → Pages**. В **Source** выбери **Deploy from a branch**, ветку **main**, папку **/(root)** и нажми **Save**.
5. Дождись успешной публикации. Ссылка появится в **Settings → Pages**. Это адрес сайта; адрес репозитория на `github.com` — другая ссылка.

Обычный адрес проекта: `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Реальный адрес нужно взять из Settings → Pages. Посетителям не нужен аккаунт ChatGPT.

Публичный репозиторий и опубликованные файлы доступны другим людям. В пакете нет учётных данных, ключей, данных реальных клиентов или файлов конфигурации Sites.

## Что проверить после публикации

- Первый экран показывает портрет.
- В разделе работ открываются четыре изображения; нажатие увеличивает макет, кнопка «Закрыть» закрывает его.
- Верхнее меню ведёт к разделам страницы.
- На телефоне блоки располагаются в одну колонку.
- Кнопки «Записаться на консультацию» пока неактивны: ссылка не была предоставлена.

Портрет создан с помощью ИИ для вымышленной Ольги. Макеты демонстрационные. Эти пометки сохранены. Доступность сайта из конкретной страны нужно проверять отдельно.

## Как обновлять

Замени нужные файлы в этом же репозитории, сохраняя имена и структуру. После сохранения в `main` GitHub Pages опубликует обновление. При замене изображения с прежним именем править HTML не нужно. Для изменения текста открой `index.html` в текстовом редакторе. Пакет не содержит формы и не собирает заявки.
